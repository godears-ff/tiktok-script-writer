# Aggregated Word Document Deliverables

Use this reference when the user asks to compile one or more scripts into a
Word document.

## Required Per-Script Structure

For every script, include the following sections in order:

1. Title and source
2. English hook
3. Chinese hook
4. English script with no timecodes
5. Chinese translation with timecodes
6. Storyboard
7. Title and cover copy
8. Caption and search text
9. CTA
10. Fact and Risk Notes
11. Sources
12. Cover prompt when requested or already part of the deliverable

## Storyboard Translation

Translate the entire storyboard into Chinese:

- Headers: `时间`, `画面`, `旁白`, `屏幕文字`, `音乐 / 音效`
- Translate every visual description
- Translate every narration or scene note
- Translate all on-screen text
- Translate BGM, SFX, pacing, and mood notes

Do not leave English headers or English cell content in the final Chinese
storyboard unless the user explicitly asks for a bilingual table.

## Caption and Search Text

Every script must include:

- Caption
- First line
- Search keywords
- Hashtags, when useful
- Chinese translation of all of the above

Do not summarize the whole video in the caption. Reinforce the hook, add
context, and use only relevant keywords or hashtags.

## Version Handling

If multiple iterations exist, preserve them as separate entries:

- `v1.0`
- `v1.1`
- `v2.0`

Label the changes or intended difference when known. Do not silently overwrite
an earlier version unless the user asks to replace it.

## Document QA

Before delivery:

- Confirm the file opens successfully
- Confirm every script has all required sections
- Confirm English scripts have no timecodes
- Confirm Chinese translations contain timecodes
- Confirm storyboard headers and cells are Chinese
- Confirm Caption, keywords, and hashtags are present
- Confirm sources and legal qualifiers are intact
- Confirm the table of contents matches the included scripts

Use a clear filename such as:

`TikTok_Social_News_Scripts_YYYY-MM-DD.docx`
